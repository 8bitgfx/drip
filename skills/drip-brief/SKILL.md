# Brief (Drip)

Step 1 of the full loop (`drip_start({ loop: "full" })`); the fast loop only states its assumptions in one line. Call `drip_guide brief` for the full rules; it records the read. (Not in your tools? ToolSearch `select:mcp__plugin_drip_drip__drip_guide`.)

- Read the project before asking anything; never ask what the repo or the prompt already answers.
- Option 1 of every question is your recommendation, marked "(Recommended)"; "Other" stays open.
- Ambition is `bold` unless the user asked for plain, safe or conservative.
- Never take a real brand's colours or fonts from memory (`drip_guide brief/brand-truth`); never invent a metric, quote, logo or customer count.

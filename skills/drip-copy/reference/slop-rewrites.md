# Copy: slop rewrites

Before and after for the copy tells AI-made interfaces repeat, grouped by where they appear. Use it to calibrate how far to cut. The product in most rows is a made-up invoicing app called Ledger; swap in the real product's nouns.

## How to rewrite

1. **Cut first.** Deleting is the default fix. Most slop is a sentence that should not exist.
2. **Rewrite only from facts.** A replacement may state only what the product, the brief or the code already shows: its features, its data, the user's numbers. Never add a speed, a count, an integration or a benefit you cannot point to.
3. **Nothing true to say?** Delete the string. If it is a heading or button that must stay, use the plainest true words and list it for the user.
4. **Unverifiable claims** (customer counts, uptime, quotes, logos) already in the code: leave them and list them for the user to confirm. Deleting real proof costs as much as keeping fake proof.
5. **Keep the user's own words** when they wrote them, even if a rule would flag them.

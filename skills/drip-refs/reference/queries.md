# Reference queries: patterns that find good work

A query is a bet on which words designers put in their shot titles and tags. Nouns win: surfaces (`dashboard`, `pricing page`), patterns (`bento grid`, `data table`), schools (`swiss`, `brutalist`, `editorial`), artifacts (`timetable`, `menu`, `annual report`), conditions (`dark mode`, `empty state`). Adjectives everyone uses (`modern`, `clean`, `beautiful`, `minimal` on its own) return the median.

## The query grammar

```
[subject or category] + [quality or school] + [medium or surface]
  fintech            +  swiss              +  dashboard
  bakery             +  editorial          +  website
  podcast            +  —                  +  record sleeve      (subject world)
```

- Use 2-4 words. Long sentences dilute the match.
- Change one word at a time between related queries to learn what each word buys.
- Pair a query with a `category` to cut noise: `web-design`, `product-design`, `mobile`, `typography`, `branding`, `print`, `illustration`, `animation`.
- Run subject-world queries in `print`, `branding` or `typography`: the best non-screen references live there.
- Every keyword search caps at about 2 pages. The query's real job is to surface tags and designers to go deeper with.

## Subject-world prompts by product kind

The strongest directions often come from an artifact the audience already knows by heart. One or two of these per task, never the whole board.

| Product kind | Artifacts to search |
|---|---|
| Logistics, shipping | shipping label, freight manifest, departure board, container markings |
| Finance, accounting | annual report, ledger, banknote, cheque, stock table in a newspaper |
| Health, pharmacy | pharmacy label, medical chart, anatomy plate, prescription pad |
| Food, restaurant | menu, packaging, market stall sign, recipe card |
| Music, audio | record sleeve, gig poster, mixing desk, liner notes |
| Developer tools | technical manual, blueprint, Swiss poster, railway timetable |
| Education | textbook spread, exercise book, periodic table, school timetable |
| Travel, hotels | luggage tag, travel poster, boarding pass, hotel key card |
| Sport, fitness | race bib, scoreboard, stadium signage, training log |
| Outdoors | topographic map, trail sign, field guide, seed packet |
| Fashion, beauty | lookbook, perfume packaging, garment label, fashion magazine |
| Civic, government | public information poster, wayfinding signage, ballot design |
| Kids, family | picture book, board game box, stickers, crayon packaging |
| Real estate, architecture | floor plan, architectural drawing, estate agent board |

On an Operate or Read surface, never take the world from the tool the audience operates (a terminal for developers, a cockpit for pilots): it comes back as a costume. Take a graphic tradition instead (a manual, a timetable, a newspaper's wayfinding).

## Words that work as tags

Schools and styles: `swiss`, `brutalism`, `neubrutalism`, `editorial`, `bauhaus`, `memphis`, `y2k`, `retro`, `minimalism`, `maximalism`, `skeuomorphism`, `claymorphism`.
Patterns: `bento`, `kanban`, `data visualization`, `onboarding`, `empty state`, `pricing`, `checkout`, `sidebar`.
Media and craft: `typography`, `lettering`, `riso`, `halftone`, `3d`, `illustration`, `motion`, `photography`.
Conditions: `dark mode`, `light mode`, `mobile`, `responsive`, `accessibility`.

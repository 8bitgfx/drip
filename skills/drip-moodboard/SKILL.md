# Moodboard (Drip)

Steps 3-5 of the full loop; the fast loop deals a layout with `layout_deal` instead. Call `drip_guide moodboard` for the full rules; it records the read. (Not in your tools? ToolSearch `select:mcp__plugin_drip_drip__drip_guide`.)

- Write 3-5 choice criteria before forming any direction, each able to fail a direction.
- 2-3 directions that differ in idea; a palette or font swap is the same idea rendered twice.
- Each direction is named like a movement with a 3-sentence manifesto, rendered at equal fidelity; no strawman.
- The critic ranks before the user sees anything; chosen = locked, never graft losers onto the winner.

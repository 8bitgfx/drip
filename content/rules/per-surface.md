# What changes by surface

| | Landing / marketing (persuade) | App / dashboard (operate) | Docs / content (read) | Mobile app screens | Portfolio / launch (experience) |
|---|---|---|---|---|---|
| Ambition | Full point of view, one signature moment | Precision, speed, familiar patterns | Typography and rhythm | Native feel, thumb reach | Maximum; break conventions with intent |
| References from | `refs_site` on shipped sites; `refs_tag` landing page | `refs_tag` dashboard, saas, product design; Mobbin | Editorial sites, docs of loved tools | `refs_feed` mobile; Mobbin | `refs_site` on strong studio and artist sites |
| Type sizes on a screen | The 7 roles of `kit/base.css` (Display ~127px at 1440) | 5 (page title, section, body, small, mono for data) | 4-5 | 4 | The 7 roles; Display at full size or bigger |
| Body size | 18px (17 on phone) | 13-15px | 17-19px | 16-17px | 18px (17 on phone); never smaller "for elegance" |
| Density | Sections 96-176px apart, earned by mass; ~80 words a screen | Dense: 4/8px rhythm, 32-40px rows | Comfortable measure 60-75ch | 16px gutters, 44px targets | The work fills the screen; a picture in every section |
| Colour | Committed or drenched at page scale; the accent marks the action | Accent for primary actions and selection only; status colours matter | Near-monochrome | System-like, one accent | Expressive |
| Imagery | Real product UI and directed photography | Data, charts, avatars; little decoration | Diagrams, code | Content images | The work itself, big, from the first screen |
| Motion | One entrance moment + meaningful scroll reveals, sparingly | Feedback only (150-200ms), no decoration | Almost none | Gestures, sheets, springs | Choreographed |
| Must have | Clear "what it is" in 5 seconds, real proof, one primary CTA | Empty/loading/error states, keyboard paths, tables that scan | Navigation, search, anchors | Safe areas, 100dvh, no input zoom | Performance despite effects |
| Surface guide | `drip_guide playbook` | `drip_guide app` | `drip_guide type` + `layout` | `drip_guide mobile` | `drip_guide playbook` |

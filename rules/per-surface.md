# What changes by surface

| | Landing / marketing (persuade) | App / dashboard (operate) | Docs / content (read) | Mobile app screens | Portfolio / launch (experience) |
|---|---|---|---|---|---|
| Ambition | Full point of view, one signature moment | Precision, speed, familiar patterns | Typography and rhythm | Native feel, thumb reach | Maximum; break conventions with intent |
| References from | `refs_tag` landing page, web design; Godly, Land-book | `refs_tag` dashboard, saas, product design; Mobbin | Editorial sites, docs of loved tools | `refs_feed` mobile; Mobbin | Godly, Awwwards, `refs_feed` popular |
| Type sizes on a screen | 4 (display, h2, body, small) | 5 (page title, section, body, small, mono) | 4-5 | 4 | free |
| Body size | 17-20px | 13-15px | 17-19px | 16-17px | free |
| Density | Airy: sections 96-160px apart | Dense: 4/8px rhythm, 32-40px rows | Comfortable measure 60-75ch | 16px gutters, 44px targets | free |
| Colour | Accent used for one action per view | Accent for primary actions and selection only; status colours matter | Near-monochrome | System-like, one accent | Expressive |
| Imagery | Real product UI and directed photography | Data, charts, avatars; little decoration | Diagrams, code | Content images | Hero art |
| Motion | One entrance moment + meaningful scroll reveals, sparingly | Feedback only (150-200ms), no decoration | Almost none | Gestures, sheets, springs | Choreographed |
| Must have | Clear "what it is" in 5 seconds, real proof, one primary CTA | Empty/loading/error states, keyboard paths, tables that scan | Navigation, search, anchors | Safe areas, 100dvh, no input zoom | Performance despite effects |
| Surface guide | `drip_guide landing` | `drip_guide app` | `drip_guide type` + `layout` | `drip_guide mobile` | `drip_guide direction` |

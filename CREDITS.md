# Credits

Drip's skills are a fusion: the ideas below were studied, merged and rewritten in Drip's own words,
organised by craft instead of by source. Where a source's licence allows adaptation, it is credited
here with its notice; where it does not, Drip only paraphrases ideas (no copied text or code).

| Source | Author | Licence | What Drip took |
|---|---|---|---|
| [Impeccable](https://github.com/pbakaus/impeccable) | Paul Bakaus | Apache-2.0 | The design-director stance, surface modes, process, critique rubric, DESIGN.md convention |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | Leonxlnx | MIT | Anti-slop rules, one system / one section per screen, real imagery, finish gate |
| [Emil Kowalski's skills](https://github.com/emilkowalski/skills) | Emil Kowalski | MIT | Interaction and animation craft |
| [Make Interfaces Feel Better](https://github.com/jakubkrehel/make-interfaces-feel-better) | Jakub Krehel | MIT | Detail checklist: surfaces, typography, icons, motion restraint |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Next Level Builder | MIT | Style, palette, font-pairing, chart and UX-guideline knowledge |
| [Hallmark](https://github.com/Nutlope/hallmark) | Hallmark contributors | MIT | Brand truth, directions and genres, gates, anatomy |
| [unslop-ui](https://github.com/felipebasurto/unslop-ui) | Felipe Basurto | MIT | UI copy de-slop |
| [Stageshow](https://github.com/benjitaylor/skills) | Benji Taylor | MIT | Faux product UI and animated demos |
| [frontend-design](https://github.com/anthropics/skills) | Anthropic | Apache-2.0 | Aesthetic direction, typography that avoids templated defaults |
| [Web Interface Guidelines](https://github.com/vercel-labs/agent-skills) | Vercel | not stated | Inspiration only (paraphrased): accessibility and interaction checklist |
| animate / choreograph / animation-performance / mobile-native skills | — | not stated | Inspiration only (paraphrased): motion decisions, choreography, frame budget, mobile web feel |

Component libraries, icon sets, fonts and reference sites listed in `data/catalogue.json` belong to
their authors; Drip links to them and never redistributes them.
